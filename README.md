# Gen12 Studio

Build Gen12 — Free AI Creative Studio



Create a modern, premium, fully responsive AI creation website called Gen12.



Core concept



Gen12 is a 100% free AI creative studio where users can create images and videos using AI.



There are NO paid plans.

There are NO subscriptions.

There are NO premium/locked tools.

Every tool on Gen12 should be presented as free to use.



The website should feel like a professional AI platform similar in quality and usability to modern AI creative platforms such as Kling, Runway, and other leading AI generation websites, but with its own unique Gen12 branding and interface.

IMPORTANT FUNCTIONAL REQUIREMENTS

Use reusable components.



Create proper routing for:

- /create

- /video

- /image-video

- /image

- /voice

- /avatar

- /tools

- /explore

- /creations

- /profile

- /login

- /signup



The frontend should be fully functional and polished.



For AI generation, structure the application so that an AI generation API/model can be connected later.



Do NOT pretend that AI generation is working if no backend model/API is connected.



Create clear API integration points for:



- Text-to-video

- Image-to-video

- Text-to-image

- AI voice

- AI avatar



Use loading states, error states, empty states, and success states.



For the first version, use realistic demo generation states and sample content where an actual AI backend is unavailable.
